# 任务一：环境配置

## 1.你是如何判断自己应该安装哪个版本的PyTorch的？

先查了电脑的显卡配置：NVIDIA RTX系列显卡，直接安装CUDA版本的PyTorch

## 2.在此过程中遇到了什么报错(如conda命令找不到，依赖冲突，网络超时等）？你是如何解决的？

### 问题一：安装到了cpu版本

解决方式：可能是自动匹配了默认的cpu，卸载了cpu版本后下载CUDA版本，最后验证安装成功

### 问题二：下载PyTorch速度太慢

解决方式：中断了当前下载，尝试了阿里云，清华源等，最后发现南开大学开源非常稳定，用了十几分钟就下好了

### 问题三：GitHub网页不稳定

解决方式：切换多个网络热点没用后，下载了Watt Toolkit加速器，开启加速后顺利注册账号
